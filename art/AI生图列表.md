# 校门口烤肠摊 · 全图画版 AI 生图列表

按当前正式版 `versions/stable-v30` 的实际内容整理（10 个顾客、3 个打包盒、7 个升级、3 个道具、3 种酱 + 2 种小料）。
共 **约 170 张**，建议按 P0 → P1 → P2 的顺序生成，每批生成完就替换进游戏试玩。

---

## 一、通用设定（每条提示词后面都要拼上）

**【风格】**（欧卡 = 欧美卡通，参考《卡通农场》《部落冲突》《胡闹厨房》的 2D 手游美术）
> 欧美卡通手游美术风格，2D 手绘，造型圆润夸张，比例Q版，块面厚实有体积感，明暗交界清晰，高饱和明快配色，深棕色粗描边，带少量手绘笔刷质感，高光干净利落，傍晚放学时分的暖黄色夕阳光，阴影偏蓝紫色，中国小学校门口生活题材，休闲手游画面，精致完成度高

**【单物件】**（所有需要抠图的切图都加这句）
> 单个物体居中，纯白色背景，无投影，无文字，完整不裁切，游戏图标/道具切图

**【反向提示词】**
> 写实照片，日系动漫，二次元大眼睛，扁平极简，线稿，水彩，像素风，模糊，文字，水印，logo，多余的手指，畸形，杂乱背景

> 想要更立体的「3D 欧卡」质感（类似《荒野乱斗》《皇室战争》），把【风格】开头的「2D 手绘」换成「3D 卡通渲染，软陶质感，柔和全局光」，并删掉「深棕色粗描边」。

**欧卡造型要点**（写角色和物件时都适用）
- 角色头身比约 1:2.5，大头、大手、大脚，五官和表情夸张
- 物件比真实的更圆、更胖、更「可捏」，边角都倒圆
- 每个物件有明确的亮面、暗面、高光三层，不要平涂

**关键色**（可加进提示词里锁色）：校服蓝 #2F5FB3、红领巾红 #D7261E、小黄帽黄 #F5B82E、黑板绿 #2F4A3B、课桌木色 #D9B685、描边深棕 #2B1A12

**生成技巧**
- 先生成 **第 0 张风格基准图**，满意后把它作为「参考图 / 风格参考」喂给后面每一张，保证画风统一。
- 角色先出 **设定图**（三视图 + 表情表），之后每个表情都带上这张设定图做角色参考。
- 文字一律不让 AI 画（AI 写中文容易错），招牌、按钮、校名留空，由程序叠字。
- 序列帧动画 AI 很难画连贯，列表里只出 **关键姿势**，动起来交给程序（位移、缩放、旋转、抖动）。

## 十七、生成后处理

1. **抠图**：白底切图用抠图工具去背景，导出 PNG 透明底；黑底的光效类（火光、蒸汽、光圈、闪光）用「滤色 / 叠加」混合，不用抠。
2. **缩到目标尺寸**：AI 一般出 1024 以上，按列表尺寸缩小（这是 @2x 尺寸，游戏里显示一半大）。
3. **压缩**：转成 WebP（小红书小工具支持 webp），质量 80 左右。
4. **控制体积**：小工具首包要小，全部美术建议控制在 3 MB 以内；背景用 JPG / WebP，角色和图标用 WebP。
5. **命名**：小写英文 + 下划线，和列表里的文件名一致，方便程序直接替换。
